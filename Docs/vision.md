# Vision

## Mission

Career OS est un système **personnel** (un seul utilisateur : moi) pour piloter ma transition vers AI Engineer.

Il centralise objectifs, compétences et progression pour transformer une ambition en plan mesurable.

## Contexte

Expérience BIM / conception numérique → Bachelor Développeur Python → cible Data / ML / IA, puis activité indépendante.

## Périmètre MVP

| Module | Rôle |
|--------|------|
| Dashboard | Vue d’ensemble (objectif principal, skills, avancement) |
| Goals | CRUD objectifs |
| Skills | CRUD compétences + niveau 0–100 |

## Hors MVP (plus tard)

Projects, Journal, Formations, Documents, candidatures, auth multi-utilisateur, FastAPI, PostgreSQL, assistant IA / RAG.

Ces sujets restent des idées d’évolution, **pas** des engagements d’architecture actuelle.

## Critères de réussite

- Utilisé régulièrement
- Remplace les notes dispersées pour goals / skills
- Reste simple à faire évoluer
- Sert aussi de démonstration technique Python

## Devise

> Ce qui se mesure s’améliore. Ce qui se visualise se pilote.
